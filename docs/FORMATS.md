# Supported Formats

## Import Formats

### SRT

Industry-standard subtitle format widely used in video production.

### WebVTT

Modern web caption format designed for HTML video playback.

### LRC

Synchronized lyric format commonly used in music applications.

### TXT

Plain text import for quick workflows.

### JSON

Structured synchronization projects and data exchange.

### Direct Text Input

Paste content directly into the editor.
